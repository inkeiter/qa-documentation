# 📚 QA Documentation Portfolio

В этом репозитории собраны примеры тестовой документации, созданные в процессе обучения и коммерческой работы. Здесь представлены артефакты, демонстрирующие навыки тест-дизайна, оформления баг-репортов и создания чек-листов.

## 📂 Структура репозитория:
*   **[Checklists](./checklists)** — примеры чек-листов для функционального тестирования.
*   **[Test Cases](./test-cases)** — структурированные тест-кейсы (в формате таблиц или Markdown) с шагами и ожидаемыми результатами.
*   **[Bug Reports](./bug-reports)** — примеры оформленных баг-репортов с шагами воспроизведения, ожидаемым и фактическим результатом.

## 🛠 Используемые инструменты и подходы:
*   Техники тест-дизайна (эквивалентные классы, граничные значения).
*   Оформление задач в Jira (структура баг-репортов).
*   Работа с требованиями.
