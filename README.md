# 📚 QA Documentation Portfolio

> 🇷🇺 Русская версия: [README.ru.md](README.ru.md)

This repository contains examples of test documentation created during my training and commercial work. It presents artifacts that demonstrate test design skills, bug report writing, and checklist creation.

## 📂 Repository structure:
*   **[Checklists](./checklists)** — examples of checklists for functional testing.
*   **[Test Cases](./test-cases)** — structured test cases (in table or Markdown format) with steps and expected results.
*   **[Bug Reports](./bug-reports)** — examples of well-formatted bug reports with steps to reproduce, expected results, and actual results.

## 🛠 Tools and approaches used:
*   Test design techniques (equivalence partitioning, boundary value analysis).
*   Writing tasks in Jira (bug report structure).
*   Working with requirements.
