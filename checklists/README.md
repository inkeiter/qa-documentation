# Чек-лист: Тестирование формы авторизации (Login Functionality)

**Объект тестирования:** Форма входа в систему.
**Тип тестирования:** Функциональное тестирование.

- [ ] Отображение полей ввода для логина и пароля.
- [ ] Маскирование вводимых символов в поле «Пароль» (отображение в виде точек/звездочек).
- [ ] Блокировка кнопки «Войти» при пустых полях (валидация обязательных полей).
- [ ] Валидация неверных учетных данных (появление сообщения об ошибке).
- [ ] Успешная авторизация при вводе валидных данных (редирект в личный кабинет).
- [ ] Функциональность восстановления пароля (переход по ссылке «Забыли пароль?»).
- [ ] Проверка работы клавиши Enter для отправки формы.
