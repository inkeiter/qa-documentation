# Чек-лист: Тестирование формы авторизации

- [ ] Поле "Логин" принимает валидные данные.
- [ ] Поле "Пароль" скрывает вводимые символы (звездочки).
- [ ] Кнопка "Войти" неактивна, пока поля пустые.
- [ ] При неверном пароле появляется сообщение об ошибке "Неверный логин или пароль".
- [ ] При пустом логине появляется сообщение "Заполните поле".
- [ ] Работает восстановление пароля по ссылке "Забыли пароль?".
