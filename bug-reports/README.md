# Отчет о дефекте: Кнопка «Оплатить» блокируется при вводе валидного промокода (BUG-042)

**ID дефекта:** BUG-042
**Краткое описание (Summary):** Кнопка «Оплатить» становится неактивной после применения промокода.

**Предусловия:**
1. Пользователь авторизован.
2. В корзине находится минимум один товар.

**Шаги воспроизведения (Steps to reproduce):**
1. Перейти в раздел «Корзина».
2. Ввести валидный промокод в соответствующее поле.
3. Нажать кнопку «Применить».
4. Нажать кнопку «Оплатить».

**Фактический результат (Actual Result):**
Кнопка «Оплатить» теряет свойство кликабельности (становится серой, атрибут `disabled`). Переход на страницу оплаты не происходит.

**Ожидаемый результат (Expected Result):**
Кнопка «Оплатить» остается активной, происходит переход на страницу платежного шлюза с учетом скидки по промокоду.

**Severity (Серьезность):** Critical (Критическая) — блокирует основной бизнес-процесс (покупку).
**Priority (Приоритет):** High (Высокий) — требует немедленного исправления.
**Окружение (Environment):** ОС: macOS Sonoma; Браузер: Google Chrome v.120; Разрешение экрана: 1920x1080.
